The problem

In most cafés, guests wait for a waiter, orders get misheard between table and kitchen, and owners work out the day’s sales in a notebook.

OrderKhaja replaces that with one system. Guests scan the QR on their table and order from their phone — no app, in English or Nepali. Staff see every table live. Owners see the money.

What I built

  • Multi-tenant SaaS: any café signs up and goes live the same day, with a free trial and plans priced by monthly orders
  • Live floor and order views with ringing alerts and web-push, a kitchen screen and thermal KOT printing
  • Bills with 13% VAT and service charge; payment by Khalti, eSewa, Fonepay/bank QR with the amount pre-filled, cash or prepaid card
  • Role-based staff logins, discount codes, loyalty, stock, sales reports and day close

How it’s engineered

  • Tenant isolation enforced in PostgreSQL with row-level security policies
  • Self-run security audit, fixed in a hardening migration: server-side order-total checks, column-level grants, rate limits, security headers
  • CI runs lint, type-check, tests and a production build on every push
  • Daily database backups, a monthly restore test and uptime checks every 15 minutes

Principles, and where they show up

  1. i.

    Isolation by default

    Every café shares one database, so separation is enforced by PostgreSQL row-level security — not left to application code to remember.

    OrderKhaja · RLS policies

  2. ii.

    Never trust the client’s total

    Prices and order totals are re-checked in the database, so a tampered phone can’t change a bill. I found that gap in my own audit and closed it.

    OrderKhaja · security hardening

  3. iii.

    Boring, proven reliability

    CI on every push, daily backups and a restore test every month. A backup you’ve never restored is only a hope.

    OrderKhaja · GitHub Actions

  4. iv.

    Made for where it’s used

    Khalti, eSewa and bank QR, bills with VAT, a menu in Nepali, and no app for guests — local details decide whether software gets adopted.

    OrderKhaja · payments & i18n
